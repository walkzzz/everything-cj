## 一、项目概述

### 1.1 项目背景

Everything-CJ 是仓颉编程语言实现的高性能本地文件秒级搜索工具，基于 NTFS MFT 实现毫秒级文件名检索。

### 1.2 核心价值

```
✅ 基于 NTFS MFT 秒级索引（非遍历扫描）
✅ 搜索响应 <100ms，输入无卡顿
✅ 内存占用 <50MB（数十万文件）
✅ 本体 <500KB，轻量绿色
❌ 不搜索文件内容（仅文件名）
```

## 三、功能性需求

### 3.1 核心搜索能力 (P0)

| ID | 需求 | 描述 |
|----|------|------|
| F001 | 实时匹配 | 输入关键词，实时匹配文件名、文件夹名 |
| F002 | 部分匹配 | 输入片段，匹配包含该片段的文件 |
| F003 | 通配符 | `*` 任意字符、`?` 单个字符 |
| F004 | 高级语法 | ext:、path:、size:、date:、type: 过滤 |

### 3.2 索引管理能力 (P0)

| ID | 需求 | 描述 |
|----|------|------|
| F101 | MFT自动索引 | 自动读取NTFS磁盘MFT，秒级建立索引 |
| F102 | 非NTFS索引 | U盘、移动硬盘手动文件夹索引 |
| F103 | 实时监控 | 新增、删除、重命名文件，索引自动更新 |
| F105 | 排除列表 | 指定磁盘/文件夹不加入索引 |

|----|------|------|
| F201 | 结果展示 | 文件名、路径、大小、修改时间 |

| F203 | 快捷键 | 回车打开、Ctrl+O打开路径、Ctrl+C复制 |
| F204 | 结果排序 | 名称、大小、修改时间升降序 |

### 3.4 程序基础功能 (P0)

| F305 | 配置保存 | 界面布局、搜索选项、索引配置 |

## 四、非功能性需求

### 4.1 性能需求

| ID | 需求 | 目标值 |
|----|------|--------|
| NFR-001 | 索引构建 | NTFS盘 < 1秒 (10万文件) |
| NFR-002 | 搜索响应 | < 100ms |
| NFR-003 | 内存占用 | < 50MB (10万文件) |
| NFR-004 | 软件体积 | < 500KB |
| NFR-005 | 增量更新 | 文件变更 < 100ms |

### 4.2 兼容性需求

| ID | 需求 | 描述 |
|----|------|------|
| C-001 | 操作系统 | Windows 10/11 |
| C-002 | 文件系统 | NTFS (MFT)、FAT32/exFAT (扫描) |
| C-003 | 权限 | 管理员/普通用户 |

### 4.3 限制与约束

| ID | 约束 | 说明 |
|----|------|------|
| L-001 | 不搜索文件内容 | 仅文件名检索 |
| L-002 | FAT32/exFAT 慢 | 只能文件夹扫描索引 |
| L-003 | 网络盘限制 | 只能手动添加文件夹索引 |
| L-004 | 管理员权限 | 完整读取NTFS MFT需要管理员 |
